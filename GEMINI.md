Las instrucciones de este proyecto están en [AGENTS.md](AGENTS.md).

Resumen: este repositorio es una herramienta (`vtr`) para grabar video tutoriales
de aplicaciones web a partir de un guion YAML. Para crear un tutorial, escribe un
guion y ejecuta `vtr record GUION --json`; no hace falta escribir código.
La referencia de acciones está en [docs/GUION.md](docs/GUION.md) y el esquema
legible por máquina se obtiene con `vtr schema`.
